# Northline

A polished, frontend-only business banking dashboard built as a portfolio project. Northline uses familiar fintech dashboard patterns with its own brand and mock company data.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- Next.js 15 App Router, TypeScript, and Tailwind CSS
- Responsive dark dashboard shell with collapsible navigation and mobile drawer
- Dashboard, accounts, transactions, bill pay, cards, payments, team spend, invoicing, accounting, and settings screens
- Client-side search, private mode, filters, modals, multi-step money movement forms, and toast feedback
- Recharts balance chart and reusable mock data

This is a UI demo only. All data is fictional and stored in local component state. There is no authentication, backend, or real money movement.

## Portfolio note

Northline is an original portfolio brand inspired by modern business banking interfaces. It is not affiliated with Mercury or any financial institution.
